# Data

The datasets used by the project are not included in this repository by default.

Primary evaluation datasets:
- Car Evaluation
- Mobile Price
- Bank Marketing

Additional source/calibration dataset:
- Census KDD

Maternal Health was evaluated separately and is not part of the primary V7 benchmark.

Please obtain the datasets from their original sources and place them in the expected project data directories before running the experiments.

Do not commit private, restricted, or redistributed datasets without checking their terms.
